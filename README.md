# Three Page Website

A small static website built for a web design homework assignment. Plain HTML, CSS, and JavaScript, with no frameworks.

## Pages
| Page | Contents |
|---|---|
| `index.html` | Home page with an intro and favorite artist section |
| `services.html` | Web services offered and a wishlist |
| `contact.html` | "Memory Book" with a form that posts messages to a public memory wall |

## Features
- Memory wall form with validation (a message and permission to display publicly are required)
- Custom cursor images
- Shared stylesheet across all pages
- WebP images for faster loading

## Run it
No build step. Open `index.html` in a browser.

> Memory wall posts live only in the page. They aren't saved anywhere and disappear on refresh.
